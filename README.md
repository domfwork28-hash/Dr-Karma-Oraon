# Dr. Karma Oraon

A story-map website about the life and work of Dr. Karma Oraon, anthropologist of the Department of Anthropology, Ranchi University, Jharkhand. Its format follows the [Schultes story map](https://www.amazonteam.org/maps/schultes/en/).

- `index.html` is the whole site in one file. It includes the world map data (Natural Earth via world-atlas) and loads d3 and topojson from cdnjs.
- All content comes from Dr. Oraon's curriculum vitae (latest entry July 2014). Map positions are city-level and approximate.

## Hosting

Open `index.html` in a browser to view it locally. To publish, enable GitHub Pages under Settings > Pages and choose the `main` branch, root folder.
